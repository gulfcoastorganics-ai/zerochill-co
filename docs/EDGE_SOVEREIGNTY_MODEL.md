# Edge Sovereignty Model

The edge sovereignty model describes how ZeroChill Co places compute, policy, and visibility close to the operator.

## Sovereignty Goals

- Operator-owned compute
- Local state retention
- Minimal cross-boundary data movement
- Clear review and escalation paths

## Edge Nodes

Edge nodes are treated as controlled infrastructure units, not disposable cloud instances.

## Autonomous Compute Layers

Autonomous compute layers may perform local orchestration, but they do not replace operator authority.

## Control Surfaces

- Tactical workstations
- Local admin panels
- Relay-approved sync channels
- Restricted service endpoints
