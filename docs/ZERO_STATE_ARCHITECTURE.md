# Zero State Architecture

Zero State Architecture defines the operating model for the ZeroChill Co stack: local nodes, bounded relay paths, and controlled inference surfaces.

## Core Layers

- Local node: primary execution and state ownership
- Offline inference cluster: local model workload boundary
- Relay topology: controlled sync and update routing
- Tactical workstation: operator console and review surface
- Secure edge compute: remote-adjacent runtime for hardened placements

## Architecture Principles

- Keep the model near the operator
- Keep policy visible
- Keep synchronization deliberate
- Keep the network optional

## Governance Model

Local AI governance is enforced through:

- Operator-visible policy boundaries
- Restricted relay lanes
- Minimal exposed service surface
- Explicit deployment tiers
