# Security Policy

## Responsible Disclosure

ZeroChill Co accepts responsible disclosure reports for vulnerabilities that affect the public site, asset system, or future infrastructure integrations.

## Supported Channels

- Private security email: `security@zerochill.co` or the current internal security contact once published
- GitHub Security Advisories, if enabled for the repository

## Security Philosophy

- Minimize exposed surface area
- Keep dependencies narrow
- Treat local execution as the primary trust boundary
- Prefer deterministic deployment paths over hidden automation

## Privacy-First Positioning

ZeroChill Co is designed to reduce unnecessary data movement and avoid avoidable telemetry. Reports that involve user data, preorder data, or operational secrets should be treated with confidentiality.

## Reporting Guidance

Include:

- Affected component or route
- Reproduction steps
- Impact summary
- Suggested severity
- Any relevant screenshots or logs

## Non-Disclosure Handling

Do not publicly disclose issues before the team has a reasonable opportunity to investigate and respond.
